# Verbia audio

Game-specific music, ambience, voice, and sound effects for Verbia belong in this folder.

## Background music

`cosmic-lounge-loop.ogg` is an original 32-second seamless loop created for
Verbia. It combines soft lounge chords, electric-piano-style plucks, a quiet
brushed pulse, bass, stereo delay, and a restrained cosmic shimmer. Its source
generator is `scripts/generate-verbia-music.mjs`.

## Completion effects

`board-clear-applause.mp3` and `board-master-hurray.mp3` are edited excerpts from
“Clapping hurray (cropped)” by Starlite/Zack and friends. The source recording was
released into the public domain and is available from Wikimedia Commons:
https://commons.wikimedia.org/wiki/File:Clapping_hurray_(cropped).oga
